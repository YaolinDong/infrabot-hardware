## 文件

| 路径 | 内容 |
|---|---|
| [assembly/infrabot-h7c_assembly.step](assembly/infrabot-h7c_assembly.step) | 零位姿态的整机，含关节电机，不含末端法兰（41 MB） |
| [parts/](parts) | 43 种机加工零件，每个子装配一个目录：`baselink`、`link1`–`link7` |
| [bom.csv](bom.csv) | 下方物料清单的表格版本 |
| [parts.json](parts.json) | 同样的数据，供脚本使用，含中文名和每个 STEP 文件的 SHA-256 |

装配体的分组与 [infrabot-description](https://github.com/YaolinDong/infrabot-description) 中的 URDF 一致：每个 `linkN` 目录是随 `Link_N` 一起运动的零件。电机模型按 CAD 中的位置分组，所以 J2 和 J3 的电机都在 `link2`。

## 加工说明

- **材料：** 铝合金 6061。
- **未注公差：** GB/T 1804-2000 M 级。
- **表面处理：** 喷砂 120 目，普通阳极氧化，本色。

## 校验文件

```bash
python3 -B tools/verify.py
python3 -B -m unittest discover -s tests -v
```

校验只需要 Python 3。它检查 `parts.json` 中的哈希、毫米单位、STEP 中没有本地路径、`bom.csv` 是最新的、文档链接有效。`tools/render_previews.py` 用于重新生成预览图，需要 CadQuery 的 OCP、VTK、NumPy 和 Pillow。
