## Files

| Path | Contents |
|---|---|
| [assembly/infrabot-h7c_assembly.step](assembly/infrabot-h7c_assembly.step) | Full arm at the zero pose, including the joint motors, without a tool flange (41 MB) |
| [parts/](parts) | 43 machined parts, one folder per sub-assembly: `baselink`, `link1`–`link7` |
| [bom.csv](bom.csv) | The bill of materials below as a spreadsheet |
| [parts.json](parts.json) | The same data for scripts, with Chinese names and the SHA-256 of every STEP file |

The assembly is grouped the same way as the URDF in [infrabot-description](https://github.com/YaolinDong/infrabot-description): each `linkN` folder holds the parts that move with `Link_N`. Motor models are grouped where the CAD places them, so the J2 and J3 motors are both in `link2`.

## Manufacturing

- **Material:** 6061 aluminium alloy.
- **General tolerances:** GB/T 1804-2000, class m.
- **Surface finish:** 120-mesh sandblast, then standard anodizing, natural colour.

## Check the files

```bash
python3 -B tools/verify.py
python3 -B -m unittest discover -s tests -v
```

The check needs only Python 3. It confirms the hashes in `parts.json`, millimetre units, no local paths in the STEP files, an up-to-date `bom.csv` and working links. `tools/render_previews.py` regenerates the images and needs CadQuery's OCP, VTK, NumPy and Pillow.
